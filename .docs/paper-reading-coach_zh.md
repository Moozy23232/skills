# Paper Reading Coach：论文精读教练

[English](paper-reading-coach.md)

`paper-reading-coach` 帮你把一篇学术论文或技术报告，读成“能定位原文、能讲清机制、能动手验证、也知道结论边界”的知识。

它既可以先快速梳理论文，也可以按功能顺序带读、拆解公式和图表、用小例子或代码检查结论、进行问答复习，并在多轮学习中保存精简进度。

## 它能帮你做什么

- 总结一篇已知论文，并让重要结论对应到具体章节和证据；
- 根据你的背景和目标安排阅读顺序；
- 只在真正卡住阅读时补充必要前置知识；
- 逐个解释公式里的符号、张量形状、假设、推导和边界；
- 把图表当作论证证据来读，而不是只描述视觉趋势；
- 区分论文原文、进一步推导、实际验证、外部知识和未知信息；
- 检查恒等式、论文数字、代码实现或隐藏假设；
- 围绕一小段原文诊断“到底卡在哪里”；
- 生成渐进提示、真实变式和针对具体误解的复习题；
- 根据已有笔记继续学习，避免机械重读已经掌握的部分。

它专注于读懂一篇已经选定的论文。如果主要目标是检索相关工作、判断创新性、规划新研究、做新实验或写新论文，应使用 `idea-to-paper`。

## 可以直接这样开始

先梳理论文：

```text
请使用 $paper-reading-coach 梳理这篇论文。我懂基础 Transformer，
但不了解状态空间模型。请给我一个按功能安排的阅读顺序、真正需要补的
前置知识，以及最值得谨慎验证的三个结论。
```

精读公式：

```text
请使用 $paper-reading-coach 讲解公式 7。逐个解释符号和张量形状，
补出论文省略的推导，手算一个最小例子，再给出一个直觉会失效的边界情况。
```

验证结论：

```text
请使用 $paper-reading-coach 检查论文中的分块形式和递推形式是否真的等价。
设计一个最小、确定性的测试，再加入一个故意破坏必要条件的开关，
最后明确说明这个结果不能证明什么。
```

互动复习：

```text
请使用 $paper-reading-coach 检查我对第 2、3 节的掌握程度。一次只问一道题，
我作答前不要展示答案；需要帮助时按“方向、关键思路、第一步、完整解答”
逐级给提示。
```

如果方便，可以同时提供论文或稳定链接、具体版本、学习目标、已有基础、希望的深度和可用时间。这些信息不完整也没关系；skill 会先采用保守假设，只追问真正会改变阅读路线的决定。

## 它怎样带你读论文

1. **先定位。** 找出问题、核心结论、作用机制、主要证据和限制。
2. **排路线。** 按理解功能安排顺序，在首次需要时补前置知识。
3. **讲清楚。** 从“为什么需要”走到直觉、严格表述、推导和具体例子。
4. **做验证。** 用算术、形状、极端情况、代码或小型可复现实验暴露误解。
5. **查边界。** 明确假设、缺失证据、替代解释，以及每项结果不能推出什么。
6. **主动回忆。** 通过作答、渐进提示、变式和后续复习检验真实掌握程度。

对于重要结论，它会把五类信息分开：论文明确写出的内容、根据论文推导出的内容、实际运行或重算验证的内容、来自外部来源的背景，以及目前仍不知道的部分。

## 通常会得到什么

| 你的需求 | 典型产出 |
|---|---|
| 快速了解论文 | 论文地图、贡献概述、阅读顺序和谨慎点 |
| 系统精读 | 学习单元、前置知识桥梁、原文位置和回忆检查 |
| 公式拆解 | 符号与形状表、逐步推导、最小例子、假设和边界 |
| 图表拆解 | 坐标与对照关系、能够支持的结论、混杂因素和解释限制 |
| 验证结论 | 可复现检查、观测结果、能够支持的解释和明确的非结论 |
| 互动复习 | 逐题问答、提示使用情况、误解反馈和迁移变式 |
| 跨会话学习 | 精简阅读状态、有原文依据的要点、待解决问题和下一单元 |

## 它不会假装做到什么

- 读起来流畅，不等于已经掌握；
- 论文作者自报的结果，不等于独立验证；
- skill 补出的推导，不会冒充论文作者原本的解释；
- 外部知识不会被写成论文原文；
- 玩具实验不会被扩大成完整模型上的经验结论；
- 检查一个版本，不会默认所有版本都完全相同；
- 没有对应证据时，不会宣称论文正确、已经完整复现或已经穷尽审查。

## 设计来源

这套流程提炼了 [kimi-k3-learn](https://github.com/ViffyGwaanl/kimi-k3-learn) 及其[在线学习系统](https://kimi.papertok.ai/#s0-1)中最有价值的做法：让解释锚定原文证据、让数值实验真的运行、用“故意破坏条件”暴露关键假设、用渐进提示和主动回忆检查掌握程度，并用限定上下文的提问包减少编造。这个 skill 把这些原则泛化成不依赖具体工具的论文阅读流程，不复制原项目的网站实现或学习内容。
